The Living Room serves as the main hub of the game.

Display the following options whenever the player is in the Living Room:

```
1. Investigate Sofa Area
    
2. Investigate Dining Area
    
3. Investigate Elevator Area
    
4. Go To
    
5. Inventory
    
6. Exit
```

### Menu Behavior

```
- **Investigate Sofa Area:** Opens the Sofa Area investigation menu.
    
- **Investigate Dining Area:** Opens the Dining Area investigation menu.
    
- **Investigate Elevator Area:** Opens the Elevator Area investigation menu.
    
- **Go To:** Displays the available room navigation options.
    
- **Inventory:** Displays acquired keys and the Notebook, if accessed.
    
- **Exit:** Asks the player to confirm before terminating the game.
```

// The player enters a numerical selection to choose an option.
