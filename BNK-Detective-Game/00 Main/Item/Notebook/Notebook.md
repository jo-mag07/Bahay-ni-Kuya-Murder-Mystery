# Notebook

## Item Information

- **Item ID:** IT-001
- **Item Name:** Notebook
- **Item Type:** Special Progression Item
- **Found In:** Boys Bedroom
- **Found At:** Study Desk
- **Required Puzzle:** RD-005
- **Answer:** NOTEBOOK
- **Status:** Confirmed

## Purpose

```
The Notebook is a special progression item that activates the final investigation phase.

It does not unlock a room and is not classified as a key.
```

## Acquisition

```
The Notebook is discovered on the Study Desk in the Boys Bedroom.

The player must solve RD-005 to access its contents.
```

## Contents

```
"You have access to every room in this house.

But finding the keys was only the beginning.

Return to each room. Look closely. There is evidence you have yet to understand.

Do not overlook anything."
```

## Progression Effect

```
Once accessed:

1. The Notebook is marked as accessed.
2. Its message is displayed.
3. The final investigation phase is activated.
4. The player may revisit previously explored rooms.
5. Artificial Grass Floor becomes available in the Garden.
```

## Important Rules

```
- The Notebook is not a key.
- It does not unlock another room.
- It can only be accessed once.
- Its contents must be displayed after a correct answer.
- It activates the conditional Garden investigation.
```
