## CL-002 — Wall Clock

- **Clue ID:** CL-002
- **Location:** Confession Room
- **Object:** Wall Clock
- **Displayed Value:** 9:00 PM
- **Numerical Value:** 9
- **Clue Type:** Numerical Clue
- **Password Reference:** PW-001
- **Status:** Confirmed

### Player Discovery

`When the player investigates the Wall Clock, the game displays that the time is 9:00 PM.`

### Clue Purpose

```
The number [9] is one of the four numerical values needed to discover the final password.

The player must remember this number. The game must not explicitly identify it as part of a password.
```
