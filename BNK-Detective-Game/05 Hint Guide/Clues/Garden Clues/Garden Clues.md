## CL-003 — Flower Bed

- **Clue ID:** CL-003
- **Location:** Garden
- **Object:** Flower Bed
- **Displayed Value:** 4
- **Clue Type:** Numerical Clue
- **Password Reference:** PW-001
- **Status:** Confirmed

### Player Discovery

When the player investigates the Flower Bed, the game displays that there are four flowers.

### Clue Purpose

```
The number 4 is one of the four numerical values needed to discover the final password.

The player must remember this number. The game must not explicitly identify it as part of a password.
```
