# Boys Bedroom — Riddle Registry

## RD-005 — The Keeper of Thoughts

- **Riddle ID:** RD-005
- **Location:** Boys Bedroom
- **Object:** Study Desk
- **Special Item:** Notebook (IT-001)
- **Answer:** NOTEBOOK
- **Reward:** Access to Notebook contents
- **Status:** Confirmed

### Riddle Text

```
"I have no mind, yet hold your thoughts.
I have no voice, yet tell what was taught.
I keep the past from fading away.
What am I?"
```

Answer: `NOTEBOOK`

### Correct Answer Response

```
"You carefully open the Notebook.

Inside, a handwritten message catches your attention."
```

### Notebook Contents

```
"You have access to every room in this house.

But finding the keys was only the beginning.

Return to each room. Look closely. There is evidence you have yet to understand.

Do not overlook anything."
```

### Progression Effect

```
After the player correctly answers:

1. Notebook (IT-001) is marked as accessed.
2. The Notebook contents are displayed.
3. The final investigation phase is activated.
4. The Artificial Grass Floor becomes available during the player's next Garden visit.
```

### Incorrect Answer Response

```
"The Notebook remains closed. You cannot make out its contents."

Options:
1. Try Again
2. Return
```

### Retry Rules

```
- Answers are case-insensitive.
- Leading and trailing spaces should be ignored.
- Unlimited attempts are allowed.
- Incorrect answers have no penalty.
- The player can return without losing progress.
- The Notebook only needs to be accessed once.
```

### Optional Hints

```
1. It is something used for writing.
2. It can hold notes, ideas, and important information.
3. It is commonly made of pages bound together.
```
