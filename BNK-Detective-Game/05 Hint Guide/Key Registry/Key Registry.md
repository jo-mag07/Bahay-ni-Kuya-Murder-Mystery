## Key System Rules

```
1. Every key has a predetermined location.
    
2. Keys are never randomly generated.
    
3. Each key unlocks only its designated room.
    
4. Keys cannot be substituted for other keys.
    
5. Keys are awarded only after solving their corresponding puzzles.
    
6. Collected keys remain in the player's inventory.
    
7. Collected keys cannot be obtained repeatedly.
    
8. The Notebook is a special progression item, not a room key.
```
